FISCAL DATA API QUICK GUIDE // TREASURY AUCTIONS

This terminal connects in real-time to the official RESTful service provided by the U.S. Department of the Treasury (Fiscal Data). Zero API keys or vendor subscriptions required. Universal CORS is enabled.

PRIMARY ENDPOINT (HISTORICAL & LIVE AUCTION RESULTS)
curl -g "https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v1/accounting/od/auctions_query?page[size]=100&filter=original_security_term:in:(2-Year,5-Year,10-Year,20-Year,30-Year)&sort=-issue_date"
UPCOMING AUCTIONS ENDPOINT (SCHEDULED DEBT ANNOUNCEMENTS)
curl -g "https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v1/accounting/od/upcoming_auctions?page[size]=100&sort=-record_date"
JAVASCRIPT CLIENT QUERY EXAMPLE
const res = await fetch('https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v1/accounting/od/auctions_query?page[size]=100&filter=original_security_term:in:(2-Year,5-Year,10-Year,20-Year,30-Year)&sort=-issue_date');
const { data } = await res.json();
console.log('Clearing yield:', data[0].high_yield, 'Bid-to-cover:', data[0].bid_to_cover_ratio);
