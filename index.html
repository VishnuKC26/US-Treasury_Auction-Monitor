Fiscal Data API Integration Guide

This terminal connects directly to the official U.S. Department of the Treasury Fiscal Data REST API with zero paid vendor fees or API keys.

1. Auctions Query Endpoint

GET https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v1/accounting/od/auctions_query?filter=original_security_term:in:(2-Year,3-Year,5-Year,7-Year,10-Year,20-Year,30-Year),security_type:in:(Note,Bond),inflation_index_security:eq:No,floating_rate:eq:No&sort=-auction_date&page[size]=1000

2. Upcoming Auctions Endpoint

GET https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v1/accounting/od/upcoming_auctions?page[size]=100&sort=-record_date

3. cURL Request

curl -H "Accept: application/json" "https://api.fiscaldata.treasury.gov/services/api/fiscal_service/v1/accounting/od/auctions_query?page[size]=1"

4. Field Definitions

  • comp_accepted: Total competitive bids accepted. Denominator for indirect, direct, and dealer takedown shares.
  • allocation_pctage: Percentage of bids accepted at the cut-off / high yield.
  • Stop vs median (bp): Dispersion between high yield and median yield: (high_yield - avg_med_yield) * 100.
